# AI Conductor Benchmarks

This repository evaluates complete execution workflows, not individual skills.
Keep runner code, grading, and telemetry outside the trial's writable workspace.
Fizzy source and its license live in fixtures/fizzy; its instructions apply there.
Do not implement benchmark features in the baseline fixture.
Work on a feature branch in an isolated git worktree. Run python3 -m unittest discover -s tests.
No credentials, trial transcripts, or generated run directories belong in git.
